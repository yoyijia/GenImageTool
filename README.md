# GenImage

Your AI marketing assistant: write a prompt, pick a visual style, generate a few image versions, then auto-write social captions for the ones you keep.

## Website

**https://yoyijia.github.io/GenImageTool/**

## What it does

1. Describe the campaign still you want.
2. Choose a style (studio, lifestyle, cinematic, luxury, and more), format, and how many versions.
3. Select the versions you like.
4. Click **Done selecting · write captions** to generate Instagram, LinkedIn, and X copy plus a story overlay line.

Images are generated with [Pollinations](https://pollinations.ai). Captions are written by the built-in marketing studio. You can optionally paste an OpenAI key in **Keys** for richer caption writing.
